## Setting it up in Obsidian

1. Settings → Core plugins → enable **Templates**
2. Set the template folder to `90 Templates`
3. New note → `Ctrl/Cmd+P` → "Insert template"

Optionally enable **Templater** for auto-dates, but nothing here requires it.
